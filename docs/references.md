# External References

## Robot Platform

### Unitree Go2 ROS2 Model
- **Repo:** https://github.com/anujjain-dev/unitree-go2-ros2.git
- **Purpose:** ROS2 URDF model and driver for the Unitree Go2 quadruped. Use for simulation setup and hardware integration.

## Reinforcement Learning
